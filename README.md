# Minh Tran Cong — Portfolio

Vite + React + Three.js (React Three Fiber) + Tailwind. Content lives in `src/constants/index.js`.

```
npm install
npm run dev
```

Contact form uses EmailJS: set `VITE_APP_EMAILJS_SERVICE_ID`, `VITE_APP_EMAILJS_TEMPLATE_ID`, `VITE_APP_EMAILJS_PUBLIC_KEY` in `.env` (local) or repo secrets (deploy). The previous plain-HTML version is in `legacy/`.
